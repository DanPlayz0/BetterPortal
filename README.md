# BetterPortal

A extension to add a few features to the geffen portal.

## Deprecation Notice

As of September 3rd 2024, This extension will not be updated as the UI has changed dramatically and I see no path forward without continual access to the portal.

Thank you to all users who have either installed or used this extension. The code here will stay available for the old routes that still exist but you must manually edit the url to get to them. Most likely deprecated routes.
